Saadet on the SMK-37 Elite / Pro

UX mocks for docs/SMK37_UX.md: each screen on the panel's own 240 × 240 geometry beside the 16 pads as the design lights them, the button LEDs and the faders where they matter. The firmware draws none of this yet; the pixel-exact set comes from the renderer in phase 0 of the port.

    Pad colour grammar

    One hue: the engine's colour, the one the screen already takes on (P5 coral, FM6 blue, CZ-1 yellow, J106 lilac). Five states, told apart by colour and level, never by level alone.

    The panel, mapped

    The printed labels and Saadet's functions. The screen names the place as it always did; the manual gives this map once.

    SMK-37Saadet
    Keys C3..C637 velocity keys. The middle 27 (F3..G5) are the FM-1's; the outer 10 play notes too, through scale, chord, octave and arp. No lights.
    16 padsCHORDS or SOUNDS (AUTO follows the place; never a second keyboard); a held button's list; PATCH held the favourites; SCALE held a piano. Velocity and pressure. Lit in the engine's hue.
    K1..K4The four values at the foot of the screen, or the knob bank's four.
    K5 / K6 / K7 / K8MASTER (a virtual master, kept) / SELECT / ALGORITHM / PRESETS.
    Faders 1..4The fader bank's four (default ENV: A D S R), soft pickup, gauges on the screen while they move.
    KNOB BANK / FADER BANKTap: the next bank. Held: the picker on the screen and the pads (top row banks, bottom row pad modes).
    < / >One SELECT detent. On HOME: the previous / next sound. With a BANK button held: its bank.
    PATCH / BTHOME / SAVE. PATCH held: the favourites on the pads.
    FX, SCALE, CHORD, NOTE REPEAT, PARA, GLOBELIBRARY, SCALE, ENV, LFO, EDIT, GLOBAL.
    ARP / SEQ / SEQ PLAY / SEQ RECARP (held: the pedal) / CHORD / PLAY / the latch.
    OCTAVE- / OCTAVE+As printed. Both at power-on: HARDWARE CALIBRATION. OCTAVE- at power-on: update mode.
    Pitch / mod wheelThe sound's bend / CC1, the matrix's MODW, P5 WHEEL MOD, FM6 WHEEL.
    Sustain pedal jackSustain (as ARP held), CC64 out, polarity learned at power-on.
    TRS jackMIDI OUT (what USB MIDI sends). No MIDI IN.

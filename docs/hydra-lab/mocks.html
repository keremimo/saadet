HYDRA, WAVE LAB

Mocks of the user wave bank's editing pages (phase 2) on the panel's own 240 × 240 geometry, for review before any of it is written in firmware. The header, the four cards and the faces are drawn by the rules of ui_view.c; the waves and spectra are computed here from the factory shapes in tools/gen_hy_waves.py (64 harmonics), so what changes on a page is what the edit would do.

  • Where. EDIT on a HYDRA sound: OSC 3, then the group WAVE LAB (six pages), then MIXER. SELECT turns the pages, K1..K4 edit the four cards, and on the SMK-37 the four faders follow the cards.
  • Header. As the firmware draws a page: EDIT, the group, six dots. The pages leave the HYDRA tag off. The green already says HYDRA, and with the tag vm_header's room rule cuts the group to "WAVE L" (see the last section). A second part's PART A tag would cut it too; naming the group LAB would avoid both. The page's own name has no room in the header either, so it stands over the picture on the left (a proposal), and the wave being edited stands on the right.
  • One chain from the start wave. MIX, then SHAPE, then SPECTRUM, then H1..H8. Every picture shows the end of the chain; grey is the start, the wave as it was when the session began. Each mock is one moment of a session: WAVE before the spectrum was touched, SPECTRUM before the drawbars. The result is stored into the user wave once the knobs rest. K4 REVERT on WAVE: one detent to START plays the start (A/B), and leaving it there takes the session back.
  • Drawbar levels are measured against the start wave's H1, not as a trim. A trim could never add a harmonic the wave lacks (a sine's H2..H8), so a NEW wave could not be built from drawbars. This is the decision to look at.
  • Copy on edit. The first turn on a factory wave copies it into the first free user wave. The toast uses the firmware's single angle (›); its font has no arrow.
  • Fitting. A value wider than 54 px drops to the row face, then the label face, as vm_cols does. That is why "U5 BELL" is small on K1. The ODD/EVEN label is 60 px, wider than a column's 59 px, so SPECTRUM's K2 is EVENS (−40: the evens down, +40: the odds down, H1 kept). FORMANT (57 px) would touch PEAK, so it is FORMNT, as the factory wave of that name is spelled.

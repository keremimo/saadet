Install Saadet

Six engines on two parts: Prophet, FM6, CZ-1, JUNO-106, HYDRA and PPG, installed over USB from this page.

  • Chrome or Edge
  • A USB data cable
  • About 3 minutes

An installation didn't finish. Your FM-1 is waiting in update mode. Connect it and press Find device to finish.

  1. Connect the FM-1 or SMK-37

    Plug it straight into this computer, without a hub, and switch it on. Close other music apps and editor tabs. When the browser asks to use MIDI devices, choose Allow.

    FM-1beta

  2. Recovery bootloader Optional

    It writes the FM-1's boot area, the one step where a power cut can need hardware recovery. Leave it off if you're unsure: you can add it later from this page.

    By Julius Vitkauskas, MIT licence. github.com/jvitkauskas/m-bootloader (opens in a new tab)

  3. Install

    Back up your sounds first: Device, then Back up now, in Saadet Studio.

    Find your FM-1 or SMK-37 first.

If an installation stopped

Nothing is lost. Until an installation finishes, the FM-1 or SMK-37 starts in update mode: its screen shows UPDATING, or stays dark. That holds even after switching it off.

Connect it, open this page and press Find device. The page offers to resume, and continues from the start of the write.

Go back to M-VAVE's firmware

This writes M-VAVE's own FM-1 firmware back over the same cable. It also puts back M-VAVE's bootloader, and what Saadet saved may be lost.

  1. Download M-VAVE's firmware: FM-1.fwsc

  3. Connect the FM-1, press Find device above, then the button below.

On an SMK-37 or MKE-P37, use M-VAVE's own updater and firmware for your model instead.

Report a problem

If Saadet crashed, don't switch the instrument off: the crash record survives a restart, not a power cycle. Connect it and read the record, then send it with what you were doing.

If the FM-1 won't start

With m-bootloader: switch off, hold PLAY and switch on for its recovery menu, or hold REC for USB download mode.

Without it, the FM-1's USB recovery route can put a firmware back from a computer: felucca-bsp recovery tools

Saadet

One polyphonic synthesizer for the Felucca FM-1. Choose Prophet, FM6, CZ-1 or JUNO-106; all keyboard and accepted MIDI notes play that sound.

Playing

Each panel button opens a place: tap it again or turn SELECT to change its page. Hold a button to reveal its entries, then press a key to jump to one. HOME shows the sound, key and chord; K1–K4 edit its macros. EDIT, ENV and LFO expose the native engine controls. SCALE, CHORD, ARP and PLAY shape the performance. REC latches notes. MASTER sets the volume. OCT- and OCT+ shift the keyboard; press both to return to octave zero, or hold both for five seconds to enter update mode.

Sounds and recall

LIBRARY (the FX button) and the editor browse factory sounds and 384 shared user slots. Native Prophet, FM6, CZ-1 and JUNO-106 sounds share that library. Single native Prophet, DX7, CZ-1 and JUNO-106 tones received over USB select their engine and audition immediately. Librarians can edit the sound live with native patch dumps; DX7 parameter and JUNO-106 single-control messages also edit their active engine directly. PRESETS browses the current engine; ALGORITHM changes the engine. The sound loads when the knob rests. K2 stars a sound; turn K3 SEND clockwise to export the selected sound over USB in its native SysEx format, including current native edits when that sound is playing. Sending does not load or save a sound. Hold HOME to access favourites on the keys. SAVE chooses a slot, name and favourite; press SAVE again to store. A supported SysEx dump opens SAVE, where K1 chooses its first slot and SAVE imports it. Repeated native updates retain the chosen destination. Leaving SAVE cancels the pending import while an auditioned tone keeps playing. User library slots are written only when SAVE confirms; banks wait for import and do not replace the playing sound. In J106, select FM-1 for MIDI input and output, match Saadet’s MIDI output channel, then send a tone from LIBRARY; the librarian receives individual tones rather than automatically retrieving the whole Saadet library. The complete synth state is saved automatically while idle and restored at startup. There are no projects, patterns, songs, drum kits, recording or motion lanes.

Delete and erase

For a user sound in any LIBRARY list, turn K4 DELETE up, then tap FX to confirm the slot shown in the white header. K4 back, a SOUND move, a page change, another button, or three seconds cancels. Factory sounds have no DELETE. The saved slot and its favourite are removed; the current sound keeps playing without a saved slot. There is no undo.

GLOBAL’s last page is ERASE. Turn K1 ERASE ALL up, then hold GLO for three seconds. Letting go cancels the countdown without changing page. K1 back or leaving the page cancels arming. This removes all saved user sounds, favourites, stored engine banks, settings, panel calibration and the power-on sound, then restarts with defaults. Keep power connected while progress is shown. Firmware and built-in factory sounds stay. If your FM-1 needed hardware calibration, hold OCT- and OCT+ at power-on to calibrate it again. Erasing has no undo.

MIDI and USB

Choose OMNI or one receive channel and one output channel. Scales, chords, strum, sustain, pitch bend and modulation remain available. MPC scale-pad mode uses Bank H without switching synth tracks. Tempo and MIDI clock drive the arp.

USB capture is the stereo synth master before computer playback is added, preventing monitoring feedback. Playback and capture support 16/24-bit USB formats at 44.1 kHz; internal rendering uses native 24-bit precision independently of the selected USB format.

Insert effects have been removed; effect settings in older sounds are ignored. See the panel guide for the full control map.

Editor and backups

Open the editor for Sound, FM6, Library and Settings. Settings contains complete Saadet backup and restore. Only Saadet archives are accepted; projects and Melodee backups cannot be restored.

Saadet's saved state uses flash addresses 0xA0000/0xA1000, formerly part of Melodee project A. Saving Saadet can replace that project's data. Install or update Saadet with the installer in Chrome or Edge; read the repository README before switching from Melodee. This local fork has not been validated by physical audition or control/deadline tests.
